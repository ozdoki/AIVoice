# アプリ別プロファイル Windows 実機QA

## 前提

- テスト用にメモ帳とKoeTypeを起動する。
- APIキーや入力欄本文を画面録画・ログへ残さない。

## 実施結果

- 2026-07-15の最新Tauri production release build: 成功。
- メモ帳を前景にして設定を開き、「直前の外部入力先から作成」で `Name = Notepad`、`process = Notepad.exe` を確認した。
- Notepadのprocess-onlyプロファイルを言語「日本語」で保存し、有効設定プレビューで言語の継承元がNotepadプロファイル、クリップボードOFFの継承元が全体設定と表示されることを確認した。
- KoeTypeを終了・再起動した後もNotepadプロファイルのカードと設定が保持され、ローカル永続化を確認した。
- QA後に修正学習をOffへ戻し、設定画面を開き直してOff表示を確認した。
- テスト用Notepad QAプロファイルは、ユーザーの明示的な承認後に削除し、登録済みプロファイルが0件であることを確認した。全消去、実注入、セッションsnapshotのE2Eは未実施。
- Chrome、Slack、Office、Cursorも利用可能だったが、既存ユーザーデータや未保存文書を汚さないため自動QAは拡大しなかった。これらのアプリに関する下記手順は未確認のままとする。

## 現在対象とプライバシー

1. ✅ メモ帳を前面にしてからKoeTypeの設定を開く。
2. ✅ 「詳細 > アプリ別プロファイル」で「直前の外部入力先から作成」を押す。
3. ✅ 名前が `Notepad`、プロセス名が `Notepad.exe` であり、`aivoice.exe` ではないことを確認する。
4. タイトル条件を有効にするまでは、現在のタイトルが保存対象にならないことを確認する。
5. タイトル条件を有効にし「現在のタイトルを明示的に採用」を押した場合だけ下書きへ入ることを確認する。
6. 入力欄本文が画面・履歴・ログへ表示されないことを確認する。

## 解決順とセッション固定

1. `notepad.exe` のprocess-onlyプロファイルで言語を日本語にする。
2. 同じprocessのtitle-specificプロファイルで「結果をクリップボードに残す」だけをオンにする。
3. 有効設定プレビューで、言語とクリップボードの継承元が別プロファイルとして表示されることを確認する。
4. 録音を開始し、途中で別アプリへフォーカスを移して停止する。
5. 開始時の入力先へ注入され、開始時のclipboard設定が使われることを確認する。
6. Raw/Polish専用ショートカットでは、プロファイルのmodeよりショートカット指定が優先されることを確認する。
7. Polish録音中のプリセットボタンが無効で、開始時の表示から変わらないことを確認する。

## 競合・失敗・復旧

1. 同じprocessで同じoverride項目を持つプロファイルを複数作り、保存前に競合警告が出ることを確認する。
2. title-specific、priority降順、ID昇順の結果が有効設定プレビューと録音で一致することを確認する。
3. 設定カテゴリを移動して戻り、未保存の下書きが維持されることを確認する。
4. 保存に失敗した場合、明示的なエラーが表示され下書きが残ることを確認する。
5. `app_profiles.json` を破損させた検証環境では、空データで上書きされず読み込みエラーと「全消去・破損から復旧」が表示されることを確認する。
6. 全消去は確認ダイアログ後だけ実行され、復旧後に新規作成できることを確認する。
